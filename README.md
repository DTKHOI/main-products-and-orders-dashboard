## 7. Hướng dẫn chạy dự án
1. Tạo môi trường ảo:
   ```bash
   python -m venv .venv
   ```
2. Kích hoạt môi trường ảo:
   - Windows: `.venv\Scripts\activate`
   - macOS/Linux: `source .venv/bin/activate`
3. Cài thư viện:
   ```bash
   pip install -r requirements.txt
   ```
4. Chạy ứng dụng:
   ```bash
   python run.py
   ```
